# Employee Payroll Analysis Using Excel

## Project Overview
This beginner-friendly Excel mini project analyzes employee payroll data using formulas and data formatting techniques.

## Dataset
Contains 20 sample employee records, including employee names, departments, locations, salaries, allowances, and deductions.

## Excel Concepts Used
- Data formatting
- Arithmetic operations
- Relative and absolute cell references
- Autofill
- Named ranges
- SUM, AVERAGE, MAX, MIN, COUNTA, and COUNTIF
- Conditional formatting

## Key Outcomes
- Calculated gross, net, and annual net salaries.
- Classified employees into salary bands.
- Created an employee payroll summary.
- Counted employees by department.

## Tools Used
Microsoft Excel for the web
